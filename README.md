# 梯度与方向向量学习网站

一个沉浸式的大学数学学习空间，通过 3D 可视化和互动实验帮助学习者理解梯度和方向向量的本质。

## 🌐 网页打开方式

### 在线访问
网站已部署在 EdgeOne，可直接访问：
- **访问地址**: [https://gradient-learning.your-domain.com](https://gradient-learning.your-domain.com)
- （请替换为实际部署域名）

### 本地运行

```bash
# 克隆仓库
git clone https://github.com/your-username/gradient-learning.git

# 进入项目目录
cd gradient-learning

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

打开浏览器访问 `http://localhost:5173` 即可查看网站。

## 🎯 核心功能

### 1. 3D 曲面可视化
- 实时渲染二元函数曲面（如 z = x² + y², z = sin(x) + cos(y) 等）
- 支持旋转、缩放视角
- 渐变颜色显示高度变化

### 2. 梯度向量展示
- 橙红色箭头表示梯度方向
- 显示梯度的大小和方向
- 直观展示"最速上升方向"

### 3. 方向向量交互
- 蓝色箭头表示自定义方向向量
- 可调整方向角度
- 实时计算并显示方向导数

### 4. 坐标点输入
- 支持手动输入点 P 的坐标 (x, y)
- 实时显示该点在曲面上的高度

### 5. 数学知识讲解
- 完整的概念讲解（方向导数、梯度定义）
- 丰富的例题演示
- 实际应用场景介绍

## 📖 操作步骤

### 基础操作

1. **旋转视角**：按住鼠标左键拖动，可从不同角度观察曲面
2. **缩放视图**：滚动鼠标滚轮放大/缩小
3. **选择函数**：点击右侧控制面板的函数下拉框，切换不同曲面

### 调整点位置

1. 在右侧控制面板找到「点 P 坐标」输入区域
2. 分别输入 x 和 y 的数值（范围：-2 到 2）
3. 观察黄色球体在曲面上的位置变化

### 调整方向向量

1. 在右侧控制面板找到「方向角度」滑块
2. 拖动滑块调整方向向量角度（0°-360°）
3. 观察蓝色方向向量的变化
4. 同时查看下方显示的方向导数值

### 显示控制

- 勾选「显示梯度」：显示/隐藏橙红色梯度向量
- 勾选「显示方向向量」：显示/隐藏蓝色方向向量

建议学习顺序：

1. **概念引入** → 理解梯度的物理意义
2. **方向导数** → 学习沿任意方向的变化率
3. **梯度** → 掌握最速上升方向
4. **梯度应用** → 了解实际应用场景
5. **总结** → 回顾核心要点
