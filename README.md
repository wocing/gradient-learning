# 梯度与方向向量学习网站 - 使用说明

## 一、网站简介

本网站是一个沉浸式的大学数学学习空间，旨在帮助学习者通过**3D可视化**和**互动实验**深入理解梯度（Gradient）和方向向量（Directional Vector）的本质概念。

网站采用交互式设计，将抽象的数学概念转化为直观的视觉效果，让学习者能够亲身体验数学公式背后的几何意义。

## 三、核心功能介绍

### 功能概览

| 功能模块 | 功能描述 | 交互方式 |
|---------|---------|---------|
| 3D曲面可视化 | 实时渲染二元函数曲面 | 旋转、缩放视角 |
| 梯度向量展示 | 显示最速上升方向 | 自动计算并可视化 |
| 方向向量交互 | 自定义观察方向 | 拖动滑块调整角度 |
| 坐标点输入 | 手动定位曲面上的点 | 输入 x、y 坐标 |
| 数学知识讲解 | 完整的理论讲解和例题 | 点击导航切换章节 |

### 1. 3D 曲面可视化

- **曲面类型**：支持多种二元函数，包括：
  - 抛物面：z = x² + y²
  - 正弦曲面：z = sin(x) + cos(y)
  - 双曲抛物面：z = x² - y²
  - 高斯函数：z = e^(-x² - y²)
  
- **视觉效果**：
  - 渐变颜色：从蓝色（低）到青色（高）表示高度变化
  - 网格线：清晰显示曲面形状
  - 光照效果：增强立体感

### 2. 梯度向量展示

- **可视化形式**：橙红色箭头
- **数学含义**：指向函数值增长最快的方向
- **箭头长度**：表示梯度的大小（变化率的绝对值）

### 3. 方向向量交互

- **可视化形式**：蓝色箭头
- **交互方式**：通过滑块调整方向角度（0°-360°）
- **实时计算**：显示该方向上的方向导数值

### 4. 坐标点输入

- **输入范围**：x ∈ [-2, 2]，y ∈ [-2, 2]
- **显示方式**：黄色球体标记当前点位置
- **实时反馈**：显示该点的函数值 z = f(x, y)

### 5. 数学知识讲解

- **章节结构**：
  - 概念引入：物理背景和直观理解
  - 方向导数：定义、公式和几何意义
  - 梯度：定义、定理和重要性质
  - 梯度应用：实际场景和算法应用
  - 总结：核心要点回顾
  
- **内容特点**：
  - 详细的概念解释
  - 丰富的例题演示
  - 清晰的知识脉络

## 四、操作步骤

### 基础操作

#### 1. 旋转视角
- **操作**：按住鼠标左键并拖动
- **效果**：从不同角度观察曲面形状
- **技巧**：配合右键平移可调整观察位置

#### 2. 缩放视图
- **操作**：滚动鼠标滚轮
- **效果**：放大或缩小视图
- **技巧**：滚轮向前滚动放大，向后滚动缩小

#### 3. 选择函数
- **操作**：点击右侧控制面板的「选择函数」下拉框
- **效果**：切换不同的曲面类型
- **提示**：不同函数展示不同的梯度特性

### 调整点位置

#### 步骤 1：定位输入区域
- 在右侧控制面板找到「点 P 坐标」区域

#### 步骤 2：输入坐标值
- **方法一**：直接输入数字（范围 -2 到 2）
- **方法二**：点击输入框后使用上下箭头微调
- **注意**：输入完成后按 Enter 或点击其他区域确认

#### 步骤 3：观察变化
- 黄色球体会移动到对应位置
- 同时显示该点的函数值

### 调整方向向量

#### 步骤 1：定位滑块
- 在右侧控制面板找到「方向角度」滑块

#### 步骤 2：调整角度
- **方式一**：拖动滑块（0°-360°）
- **方式二**：点击滑块两侧的箭头微调（每次 15°）

#### 步骤 3：观察结果
- 蓝色方向向量会随之旋转
- 下方显示当前的方向导数值

### 显示控制

#### 显示/隐藏梯度向量
- 勾选「显示梯度」复选框
- 橙红色箭头会显示或隐藏

#### 显示/隐藏方向向量
- 勾选「显示方向向量」复选框
- 蓝色箭头会显示或隐藏

## 五、学习建议

### 入门学习路径

```
第1步：熟悉界面
    ↓
第2步：观察梯度方向
    ↓
第3步：尝试不同函数
    ↓
第4步：调整方向向量
    ↓
第5步：阅读理论讲解
    ↓
第6步：完成练习题
```

### 实验建议

#### 实验 1：理解梯度方向
1. 选择函数 z = x² + y²
2. 将点 P 移动到 (1, 0)
3. 观察梯度向量方向（指向 x 轴正方向）
4. 将点 P 移动到 (0, 1)
5. 观察梯度向量方向（指向 y 轴正方向）
6. **结论**：梯度指向函数增长最快的方向

#### 实验 2：方向导数与角度关系
1. 保持点 P 在 (1, 1)
2. 调整方向角度从 0° 到 360°
3. 观察方向导数的变化
4. **发现**：当方向与梯度平行时，方向导数最大；垂直时为 0；反向时最小

#### 实验 3：不同函数的梯度特性
1. 依次选择不同函数
2. 在相同位置观察梯度向量
3. **比较**：不同函数的梯度变化规律

## 六、常见问题

### Q1：为什么曲面显示不出来？

**可能原因**：
- 浏览器不支持 WebGL
- 显卡驱动需要更新
- 网络加载失败

**解决方法**：
- 使用 Chrome 或 Firefox 浏览器
- 更新显卡驱动
- 刷新页面重新加载

### Q2：为什么输入坐标后球体位置不变？

**可能原因**：
- 输入值超出范围（应在 -2 到 2 之间）
- 输入格式不正确（应为数字）

**解决方法**：
- 检查输入值是否在有效范围内
- 确保输入的是纯数字

### Q3：如何重置视图？

**方法**：
- 刷新页面（F5）
- 或者在控制面板重新选择函数
